# Руководство по работе с Google NotebookLM — Computer Science & Computer Architecture

## 1. Загрузка в NotebookLM
Загрузите все сгенерированные файлы из папки `computer_science` в новый блокнот NotebookLM.

## 2. Генерация Audio Overview (Подкаста)
В левой панели NotebookLM отметьте галочками изучаемую тему и нажмите «Customize»:
> «Обсуждайте материал на русском языке в формате академического диалога двух ведущих экспертов. Делайте акцент на глубине, доказательствах и практических кейсах по теме Computer Science & Computer Architecture. Без поверхностных упрощений и клише».
